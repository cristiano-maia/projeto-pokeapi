Projeto PokeAPI
https://cristiano-maia.github.io/projeto-pokeapi/

Projeto simples de consulta de Pokémon utilizando HTML, CSS, JavaScript e a PokéAPI.

A estrutura do JavaScript foi mantida propositalmente próxima de um exercício introdutório com `fetch()`, utilizando:

- `getElementById`
- `addEventListener`
- `fetch`
- `.then()`
- `resposta.json()`
- condicionais
- `innerHTML`
- acesso a propriedades de objetos
- acesso simples a posições de arrays com `[0]`

## Endpoint

```text
https://pokeapi.co/api/v2/pokemon/NOME_OU_ID
```

Exemplos:

```text
https://pokeapi.co/api/v2/pokemon/pikachu
https://pokeapi.co/api/v2/pokemon/25
```
